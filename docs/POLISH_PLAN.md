# งานเพิ่มโลกสามมิติและห้องชมตัวละคร

## ส่งมอบในรอบนี้

- [x] เปลี่ยนโลกจากภาพฉากหลังเป็นพื้นที่ geometry สามมิติที่เดินสำรวจได้จริง
- [x] One Piece: ดาดฟ้าเรือ ท่าเรือ ชายหาด พร้อมใบเรือ เชือก หัวสิงโต น้ำ shader ปาล์ม และหีบสมบัติ
- [x] Demon Slayer: เส้นทางวิสทีเรีย ศาลเจ้า และลานฝึกริมธาร มีต้นไม้ instancing โทริอิ โคมไฟ สะพานและหมอก
- [x] Attack on Titan: ถนนเมือง ประตูกำแพง และจุดชมเมืองบนกำแพง มีทางลาดเดินขึ้นจริงและไททันด้านนอก
- [x] กล้องเดิน WASD/Shift, ลากและลูกศรมองรอบตัว, ปุ่มเดินบนมือถือ รองรับสองนิ้วเดินพร้อมมอง
- [x] ขอบเขตเดินและสิ่งกีดขวางบนแกน XZ, คืนจุดเริ่มด้วย R หรือปุ่มสถานที่, แผนที่ตำแหน่ง/ทิศทาง
- [x] ห้องชมโมเดลทีละตัว: ลูฟี่ โซโล ทันจิโร่ เนซึโกะ รีไวล์ มิคาสะ
- [x] Orbit 360°, ซูม/จีบนิ้ว/คีย์บอร์ด, คืนมุม, หมุนอัตโนมัติ และกลับตำแหน่งเดิมในโลก
- [x] คงเอฟเฟกต์ประจำโลก สมุดสำรวจและ progress โหมดซ่อน UI เสียง และ fallback เมื่อ WebGL หยุด
- [x] จัด HUD ให้เหลือพื้นที่ดูฉากและมีมุมมองมือถือ/แนวนอน
- [x] เอาภาพปกออกจากเงื่อนไขโหลดโลก จึงเข้าโลก 3D ได้แม้ภาพปกเสีย
- [x] รวม geometry แบบแยก vertex layout, ใช้ instancing, เงานิ่งไม่คำนวณซ้ำทุกเฟรม
- [x] คืน geometry/material/texture/instance buffer/shadow map และ event listeners เมื่อเลิกใช้
- [x] README, asset manifest, ภาพหน้าจอจริงครบสถานที่และโมเดล

โมเดลเป็นแฟนโมเดล stylized สร้างด้วยโค้ด ไม่ใช่ official GLB หรือโมเดลสมจริงระดับเกม ข้อมูลที่มาอยู่ใน [ASSETS.md](ASSETS.md)

## เกณฑ์ตรวจ

`npm run test:navigation` ผ่าน 4 ชุดทดสอบเส้นทาง/ขอบเขต; `npm run build` และ `npm run test:browser` ผ่านกับ production preview ตรวจการเดิน/มอง/คืนจุด, สถานที่ทั้ง 9 แห่ง, ความสูงบนกำแพงและทางลาด, ตัวละครทั้ง 6 ตัว, orbit/zoom/หมุนอัตโนมัติ, คืนตำแหน่งเมื่อออกจากห้องโมเดล, คืน geometry เมื่อออกจากโลก, เอฟเฟกต์/สมุดสำรวจ, touch สองนิ้ว, desktop/mobile/แนวนอน/retina, reduced motion, ยกเลิก transition และภาพปกเสียแล้วเข้าโลกได้

ภาพประกอบบันทึกจาก production build ผ่าน Chromium ใน `docs/screenshots` ไม่ใช่ภาพ mockup

## งานระยะถัดไป

- โมเดล GLB ที่มี rig และ license/author/source ตรวจสอบได้ เพื่อเพิ่มความละเอียดและอนิเมชันตัวละคร
- collision ตาม mesh, บันไดและการสำรวจภายในอาคาร; ปัจจุบันเดินเฉพาะพื้นที่ภายนอกที่กำหนด
- interaction กับวัตถุ เช่น เปิดหีบ ฝึกดาบ ระบบลมใบเรือ และเส้นทาง ODM
- audio บรรยากาศและ spatial sound จากแหล่งที่ระบุสิทธิ์
- benchmark บนมือถือจริง แล้วเลือก LOD, compressed textures และ adaptive quality จากผลวัด

ยังไม่ได้อ้างว่าเสร็จสำหรับ rig, combat, ODM, แผนที่ open world ไม่จำกัด หรือ FPS บนอุปกรณ์จริง
